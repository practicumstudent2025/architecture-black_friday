# Архитектура MongoDB: Шардирование, Репликация и Кеширование

## 🚀 Быстрый старт

### Запуск финальной реализации
```bash
# Перейти в директорию с финальной реализацией
cd sharding-repl-cache

# Запустить полную инициализацию (все автоматически)
./scripts/init-all.sh
```

**Что делает `init-all.sh`:**
- ✅ Запускает все 10 сервисов (MongoDB, Redis, FastAPI)
- ✅ Инициализирует MongoDB шардирование и репликацию
- ✅ Заполняет базу 1000 тестовыми документами
- ✅ Тестирует Redis кеширование (измеряет производительность)
- ✅ Выводит подробный отчет о состоянии системы

### Проверка работы
1. **Приложение**: `http://localhost:8080`
2. **Тестирование кеширования**: `curl http://localhost:8080/helloDoc/users`
3. **Статус сервисов**: `docker compose ps`

## 🔧 Технические требования

- **Docker** и **Docker Compose**
- **Docker образ**: `kazhem/pymongo_api:1.0.0`
- **MongoDB**: 2 шарда × 3 реплики + Config Server + mongos
- **Redis**: Кеширование запросов
- **Порты**: 8080 (приложение), 27017 (MongoDB), 6379 (Redis)
